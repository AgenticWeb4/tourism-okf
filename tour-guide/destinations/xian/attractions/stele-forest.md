# 西安碑林博物馆

## 参观要点

- **核心价值**：中国现存最早、名碑最密集的石刻群之一，书法史视角极佳。
- **与城墙联游**：与 [西安城墙](city-wall.md) 南门区域相邻，常安排半日「城垣 + 碑林」。
- **深度建议**：对书法/历史爱好者可预留 2 小时；普通游客抓「国宝碑 + 基本书法脉络」即可。

## 导游话术参考

「碑林是把文字刻进石头里的图书馆——一块碑，往往就是一位古人留给长安的一页日记。」

## 实用信息

- **位置**：西安市碑林区三学街15号（文昌门内）。
- **门票与联票**：是否与城墙联售，以官方售票信息为准。
- **参观礼仪**：勿拓印、勿触摸展品（除非互动区另有说明）。
